# Руководство игрока

1. Выполните `/register` и заполните название государства, республику/монархию, религию и валюту.
   По умолчанию игроку разрешено одно активное государство; если администратор включил множественную
   регистрацию, можно зарегистрировать дополнительные. Если канал не создан, проверьте с администратором
   категорию и права бота.
2. Игровой канал приватен. Публикуйте государственные решения и события именно там; для обсуждения
   вне игры используйте другой канал. Сообщения в ветках относятся к тому же государству.
3. Для вердикта используйте `!verdict Текст поста` либо напишите пост отдельным сообщением и ответьте
   на него командой `!verdict`. Длина текста поста — не более 2000 символов; обычные сообщения без
   команды не обрабатываются и лимит не расходуют.
4. Бот учитывает эпоху, статистику, склад, лор и предыдущие события, после чего отвечает компактной
   карточкой-Reply: итог, важные последствия и изменения показателей. Внизу карточки указаны дата,
   номер вердикта и остаток постов на сегодня.
5. Вердикты могут ожидать утверждения администратора. Предложенные изменения не вступают в силу,
   пока они не применены; отрицательные балансы и неизвестные показатели запрещены.
6. `/panel` показывает карточку государства. Если у вас несколько стран, выберите нужную из списка или
   введите ID; автодополнение подскажет ваши страны. Кнопки открывают экономику, склад, историю, промышленность, армию,
   технологии, проекты и лор. Кнопка «Как играть» напоминает формат `!verdict` и лимит поста. Показатели армии (личный состав, подразделения, техника, боеприпасы, бюджет,
готовность и снабжение) можно менять и пополнять; текущая версия отслеживает их без боевой системы.
7. Лимит игровых постов сбрасывается по серверному часовому поясу. Дополнительные посты выдаёт
   администратор; редактирование старого сообщения не создаёт новый игровой ход.
8. Хронология действий сохраняется в базе. Если ответ не появился, не отправляйте действие повторно:
   outbox автоматически повторяет доставку; при длительной задержке сообщите модератору для `/post-retry`.

Торговля: `/trade-offer recipient_country_id` с суммой и ресурсами `Железо=5; Древесина=2` отправит
предложение; значения стран подсказываются при вводе ID, а если у отправителя несколько стран,
выберите нужную в поле `sender_country_id`. Передача произойдёт только после `/trade-accept offer_id`
получателем; список входящих предложений также появляется при выборе поля ID. Получатель может
вызвать `/trade-decline`. Остатки проверяются в момент сделки, поэтому устаревшее предложение может
быть отклонено движком. Денежные сделки между разными валютами требуют направленного курса, который
администратор задаёт `/exchange-rate-set`; без него денежная часть сделки отклоняется. Если действие обосновывает строительство, судья может создать проект: казна и материалы
резервируются, срок идёт по успешным ходам, затем предприятие автоматически начинает работу. Для
научной программы судья может создать одно простое исследование следующего уровня: без затрат и
предпосылок, на 1–5 успешных ходов. После завершения технология открывает следующий уровень.
Контрпредложения пока не реализованы; боевая система намеренно не входит в текущий этап.
